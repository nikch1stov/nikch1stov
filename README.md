### 👨🏻‍💻 Обо мне

Аналитик данных с четырьмя годами опыта в CRM-аналитике и антифроде в Яндексе. Люблю находить в данных скрытые потери и точки роста, а потом превращать их в результат. Мои находки помогли предотвратить потери на десятки миллионов рублей и дать более 1 млрд руб. дополнительного оборота за год.

Развиваюсь через практику. Закончил обучение в Яндекс Практикуме, прошел курс по SQL и собрал учебные проекты в портфолио (они ниже). Продолжаю учиться и применять SQL, Python и DataLens на реальных данных.

-------
### ⚒️ Технологии и навыки

- **SQL (PostgreSQL)** - выгрузка данных, joins, агрегации, оконные функции, CTE, ad-hoc анализ  
- **Python** - Pandas, Matplotlib, Seaborn, предобработка данных, EDA, визуализация  
- **BI** - Яндекс DataLens, Superset, дашборды, отчетность, интерактивная аналитика  
- **Excel / Google Sheets** - ВПР, сводные таблицы, анализ данных  
- **Анализ данных** - EDA, очистка данных, визуализация, описательная статистика  
- **Продуктовая аналитика** - бизнес-метрики (DAU, LTV, retention, конверсия), когортный анализ, воронки  
- **Статистика** - проверка гипотез, A/B тесты, статистический анализ  
- **Моделирование данных** - витрины данных, трансформация данных, качество данных  
- **Инструменты** - Git (базово), Jupyter Notebook, DBeaver, VS Code
